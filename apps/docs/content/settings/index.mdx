Settings is a page that takes over the whole window. Your sessions keep running behind it, and every transcript is where you left it when you come back.

## Open Settings

- Click the gear in the sidebar's top strip, or
- press `⌘,` from anywhere, even with the sidebar collapsed.

The tabs run down the left where the sidebar usually is. Click one, or use the arrow keys to move between them.

To leave, press `Escape` or click **Close Settings** in the top right. If a menu or a shortcut recorder is open, the first `Escape` closes that, and the next one leaves.

## The tabs

| Tab | What it holds |
|---|---|
| Appearance | Theme, light or dark, main font, UI and code font sizes, zoom, and where the side panel sits. See [Appearance](/settings/appearance). |
| Profiles | Group projects and sessions. See [Profiles](/using-carbon/profiles). |
| Servers | This Mac's background server, remote access, and the other machines you run sessions on. |
| Accounts | Which account each agent and `gh` is signed in as, and how to sign in or out. See [Accounts](/settings/accounts). |
| MCP | Add, edit and remove local agent MCP configurations. See [MCP servers](/settings/mcp). |
| Skills | Create, import and share reusable agent instructions. See [Skills](/settings/skills). |
| Transcription | Dictation models and your microphone. See [Dictation](/settings/dictation). |
| Integrations | Which app opens files, the in-app browser's Chromium, and a connected issue tracker. |
| Shortcuts | Every keyboard shortcut, each one changeable. See [Shortcuts](/settings/shortcuts). |
| Island | Configure the floating Mac panel and its global keys. See [Carbon Island](/settings/island). |
| Composer | Customize the prompt buttons above the composer. See [Composer buttons](/settings/composer). |
| Changelog | Every release and what changed in it. |
| About | Updates, the beta channel, and how to support or reach the author. |

## Profiles

Create, rename, reorder or remove profiles and assign attached projects to them. A profile filters what you see; sessions in other profiles keep running. See [Profiles](/using-carbon/profiles). The document workspace is [Spaces](/using-carbon/spaces), opened from the navigation rail.

## Servers

The **This Mac** row is the background server that runs your sessions on this Mac, with Carbon open or closed. Its **Turn on remote access** button gives it a public address that another Mac can connect to; **Stop remote access** turns that off. While it is on, the row shows the address with **Copy address** and **Copy token** buttons. See [Remote access](/reference/remote-access).

**Add server** connects a Linux machine you can SSH into, or any running `carbon serve` by its address and token. Each server row has **Rename**, **Check for updates**, **Join beta** or **Leave beta**, and **Remove**. The full walk-through is on [Connect a server](/server).

## Accounts

One block per agent, plus GitHub. Each shows who is signed in and offers Sign in, Reauthorize or Sign out. The switch beside each agent's name hides it from the agent picker in the composer. See [Accounts](/settings/accounts).

## Transcription

Download a model for dictation, pick your microphone, and choose whether other audio is muted while you talk. See [Dictation](/settings/dictation).

## Integrations

- **Open files with** — the app a filename from the chat opens in when you ⌘-click it. Lists the editors Carbon finds installed, plus Finder. Finder selects the file rather than opening it, and is used whenever no editor is picked or the pick fails. Markdown files open in Carbon's own panel instead.
- **Browser** — the Chromium that Carbon's built-in browser runs on. It is not shipped with the app; Carbon downloads it after install. The row shows its progress, offers **Retry** if the download failed, and **Remove** to take the space back. A removed copy downloads again the next time Carbon starts.
- **Issue tracker** — shown only when Linear is connected. It names the workspace and your user, and **Disconnect** makes Carbon forget the key. Sessions keep the issues they are tagged with. Connecting happens on the Issues page; see [Issues](/settings/issues).

## Shortcuts

Search, rebind, unbind or reset any shortcut. See [Shortcuts](/settings/shortcuts).

## Changelog

The release notes for every version, newest first. **View changelog** in About opens the same list.

## About

- **Updates** — **Check for updates**, then **Restart to update** once a new version has downloaded. While any session is mid-turn, the restart button is held until the turn finishes.
- **Beta updates** — **Turn on** to get new versions early, before they are fully tested. **Turn off** goes back to stable. Both ask you to confirm.
- **What's new** — **View changelog** opens the Changelog tab.
- **Support** — **Sponsor** and **Star on GitHub**.
- **Feedback** — **Open an issue** on GitHub, or **Message me**.

## Limits

- Settings opens on Appearance each time, except when Carbon sends you to a tab, such as Transcription when you press the mic with no model downloaded.
