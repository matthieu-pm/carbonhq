Carbon is a Mac app. It runs the coding agent CLIs you install yourself, so setting it up is two things: the app, and at least one agent.

## Requirements

- macOS 11 or later.
- Apple silicon or Intel. There is one universal download for both.
- At least one agent CLI: Claude Code, Codex, pi, fx or Grok Build. See [Agents](/using-carbon/agents).
- git, for branches and worktrees. A folder that is not a git repository still works, without those two.
- Optional: the GitHub CLI (`gh`), signed in. Carbon uses it to list your repositories when you attach a project, and for the pull request tab.

## Download and install

<Steps>
  <Step title="Download">
    On [carbonhq.sh](https://carbonhq.sh), click **Download for macOS**. You get a universal `.dmg` for Apple silicon and Intel.
  </Step>
  <Step title="Install">
    Open the dmg and drag Carbon into Applications. Eject the disk image after copying.
  </Step>
  <Step title="Open">
    Open Carbon from Applications. Do not run it from the disk image: Carbon cannot start its background server from a mounted installer or a temporary macOS location.

    If macOS blocks a build you downloaded from Carbon's site, see [macOS blocks Carbon](/reference/troubleshooting#macos-blocks-carbon). Signing and notarization depend on the build; do not assume a beta has passed Apple's notarization.
  </Step>
</Steps>

## Install an agent

Carbon installs no agent and stores no agent login. Each agent keeps its own, exactly as it does in your terminal. If an agent already works in your terminal, it works in Carbon.

You pick the agent in the composer's model picker. An agent that is not installed has a small red dot on its mark. Pick it anyway and the composer tells you:

> Codex isn't installed, so this session can't start.

Beside that line are two buttons:

- **Copy command** copies the vendor's own install command. Paste it into a terminal.
- **Install guide** opens the vendor's install page.

Carbon never runs the installer for you. These are the commands it offers:

| Agent | Install command |
|---|---|
| Claude Code | `curl -fsSL https://claude.ai/install.sh \| bash` |
| Codex | `curl -fsSL https://chatgpt.com/codex/install.sh \| sh` |
| pi | `curl -fsSL https://pi.dev/install.sh \| sh` |
| fx | `curl -fsSL https://fx.sh/setup.sh \| bash` |
| Grok Build | `curl -fsSL https://x.ai/cli/install.sh \| bash` |

Then sign in to the agent. [Agents](/using-carbon/agents#signing-in) says how, and [Accounts](/settings/accounts) shows who each agent runs as.

:::note
Carbon looks for each agent once and remembers the answer. If you install an agent while Carbon is running, it still reads as missing. Quit with **Quit completely** (see below) and open Carbon again, so the background process looks again.
:::

### Carbon keeps running after you quit

Your sessions run in a background process, not in the window. Close the window or quit the app and the agents keep working. Open Carbon again and you find them where you left them.

When you quit (`⌘Q`, or the window's close button), Carbon asks first:

- **Quit** closes the app. Sessions keep running in the background.
- **Quit completely** closes the app and stops this Mac's background server and its agents. Sessions on other servers keep running.
- **Cancel** keeps Carbon open.

### The browser downloads in the background

Carbon has a built-in browser, and it runs on Chromium. Chromium is not in the download, since it is a few hundred megabytes. A few seconds after the window first opens, Carbon fetches it in the background. There is nothing to click.

You can see how far it has got in Settings → Integrations → **Browser**, and on the browser tab while it is still downloading. If the download fails, Carbon tries again; you can also press **Retry** there. **Remove** deletes it; it comes back the next time Carbon starts.

## The `carbon` command line

The app includes the `carbon` command line. On launch, a release build copies it to `~/.local/bin/carbon` and installs its agent skill. It lets you and your agents start sessions, message other sessions, work with Pages and drive the browser, even with the app window closed. See [carbon CLI](/cli).

If Terminal cannot find it, try `~/.local/bin/carbon --help` and put `~/.local/bin` on your shell's `PATH`.

## Limits

- Mac only. Carbon can also run on a Linux server that you drive from the Mac app: see [Connect a server](/server).
- Carbon does not install an agent or sign you in to one. Each agent uses its own login, subscription or key.
