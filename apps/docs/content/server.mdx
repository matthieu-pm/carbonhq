Connect a Linux server to run agents away from your Mac. The app uses your Mac's SSH client to reach it, and the project files and sessions stay on the server.

## Requirements

- Linux on x86_64 or arm64, with a systemd user service available for the background server.
- SSH access from your Mac using a key. The app does not handle password prompts.
- Internet access on the server to download Carbon, the tools you choose and model responses.
- A login or API key for each agent you use, on that server. Your Mac's agent login is not copied.

git is needed for repository and worktree operations. `gh` is needed to list GitHub repositories and use GitHub features. The installer offers missing tools and reports any command that needs administrator access.

## Connect from the Mac app

<Steps>
  <Step title="Add the server">
    In the Mac app, open Settings → Servers → Add server and paste the SSH line, like `ssh root@1.2.3.4`.

    The app connects with your Mac's own `ssh`. You do not need to open a public Carbon port. If SSH asks for a password, the app shows the `ssh-copy-id` line that sets up a key. On a first connection, verify the host fingerprint before choosing **Trust and connect**.
  </Step>
  <Step title="Install Carbon there">
    If Carbon is not on the server yet, the app offers to install it. Pick what else to install: Claude Code, Codex, pi, fx and Grok Build, plus git and the GitHub CLI.

    To add the browser's Linux libraries or ffmpeg for browser recordings, run `carbon server install` in a terminal on the server and select them there.

    Carbon runs as a systemd user service, so it keeps running after you log out and comes back after a reboot. That needs linger on your user; if setup cannot turn it on, it says so, and `sudo loginctl enable-linger <user>` fixes it. If Carbon is installed but stopped, the app starts it.
  </Step>
  <Step title="Sign in">
    Each agent needs its own login on the server, and so does `gh`. Once Carbon is running there, the app shows that server's accounts, the same list as Settings → Accounts. Sign in opens Terminal on the server, running that login.

  </Step>
  <Step title="Attach a project">
    Attach a project, pick the server, and choose one of your GitHub repos, read through `gh` on that server. Carbon clones it to `~/carbon/<repo>` there. A path to a folder already on the server works too.

    Then start a session like any other.
  </Step>
</Steps>

## Install from the server instead

If you would rather install by hand, log in to the server and run:

```bash
curl -fsSL https://carbonhq.sh/install.sh | sh
```

On a fresh Linux install, this installs `carbon` and `carbon-serve` into `~/.local/bin`, then runs the setup that `carbon server install` provides. It asks which missing tools to install and starts the service. It ends by printing the SSH line to paste into Add server. If you need to finish setup later, run `carbon server install` yourself. `carbon setup` is its older spelling and still works.

Use `carbon server status` to check it. On Linux, `journalctl --user -u carbon -n 50` shows the log. See [Server commands](/cli/servers) for foreground use, stopping the service, channels and updates.

## Connect by address or pair a phone

An SSH connection from the Mac app needs no public tunnel. To connect by address, turn one on from the server:

```bash
carbon server tunnel on
```

Paste the printed address and token into Settings → Servers → **Add server** → **Use an address and token instead**. Anyone holding both can use the server. If you already have Carbon for iPhone, `carbon server pair` displays its pairing QR code. See [Remote access and sharing](/reference/remote-access).

## Updates and reconnecting

Disconnecting the Mac app leaves the server's agents running. Reconnect to pick up their current state. Settings → Servers can [update a remote server](/reference/remote-access#update-remote-servers), which restarts once its agents finish. Its release channel is separate from the app's.

## Limits

- There is no browser version of the Carbon interface.
- The app's guided SSH installer supports Linux. To reach a Mac running Carbon, use [Remote access](/reference/remote-access).
