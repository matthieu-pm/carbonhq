Spaces is Carbon's document workspace. Its documents are called **Pages**. Open **Spaces** from the app's navigation rail or press `⌘P`. Pages are enabled by default.

To group projects and sessions, use [Profiles](/using-carbon/profiles).

## Create and organize Pages

Click **New Page** in the sidebar, press `⌘⇧P`, or choose **Create → New Page**. Write a title and body. A Page can stand on its own or belong to several projects.

To link projects, open **Document display options and metadata** beside the edited date. Check projects under **Linked projects**. Each project link points to the same document; it does not make a copy.

The sidebar has **All**, **Pages**, **Linear**, project filters and **Trash**. Above the Page list, **All**, **Favorites** and **Recent** narrow the results. Recent means edited in the last week. Use the list and grid controls to change the layout, and search to find words in titles and bodies. Star a Page to favorite it. **Move to trash** and **Restore document** live in its **Document options** menu.

Pages belong to their Carbon server. **Create** also offers **New Page on …** for connected servers. A remote Page stays on its server; linking it to a project does not put it in a repository or worktree. The active Profile filters Pages by their linked projects; unlinked Pages remain visible.

## Work in tabs

Opening a Page opens a tab, or switches to its existing tab. **New tab** (+) opens another list on All. Each list tab keeps its own section, project, filter, search and layout. Sidebar choices change the active tab.

Drag tabs to reorder them. `⌘⇧[` and `⌘⇧]` move between tabs; `⌘1`–`⌘8` pick by position and `⌘9` picks the last. `⌘W` closes a tab when more than one is open. On a lone Page it returns to the list; on a lone list it leaves Spaces. Tabs are kept between launches.

## Write Markdown

The rich editor supports headings, formatting, nested lists and checklists, links, images, tables, code blocks and formulas. Type `/` to insert a block. Select text to format it. Code blocks retain their language, including Mermaid diagram source.

Open **Document options** (⋯) for **Markdown source** or **Preview**. Source mode preserves constructs outside the rich editor's schema, including HTML, frontmatter, footnotes, reference links and callouts. Pages larger than 32 KiB open in source mode. A Page body can hold up to 256 KiB.

In **Document display options and metadata**, turn on **Formatting toolbar** or **Full width**. **Open outline** shows the headings beside the document in edit or preview mode.

Changes save automatically. `⌘S` saves immediately. If another writer changes the Page, Carbon keeps your draft. Choose **Review changes** to compare it with the saved Page, then **Use saved version**, **Save my version** or **Keep editing**. Another edit before your save raises another conflict.

## History and references

Choose **Document options → Version history** to inspect earlier revisions. Restoring writes a new revision and retains the Page's current project links, favorite and Trash state.

**Use in task**, in the same menu, adds a saved Page reference to the composer. You can also choose **Reference a Page** from the composer's attachment menu or context menu. Conversation references cite a specific revision. Opening one shows that saved content, with an action to open the current Page.

**Copy document link** copies a link to the Page. **Link another Page** inserts a live link inside a document. **Linked from** lists Pages that refer to it.

## Attachments and previews

Choose **Document options → Attach files…**. Images can appear inline; file links open a preview where the file type supports it. Preview renders formulas and Mermaid diagrams. Attachments can be up to 20 MiB and stay available independently of sessions and worktrees.

## Agent access

Agents can search, read and update the same Pages through `carbon pages`. Writes require the revision they read, so a stale write leaves the document unchanged. Ask an agent to read a Page before editing it. Run `carbon pages --help` for the available commands.

## Linear documents

Choose **Create → Import from Linear**, or open **Linear** in the sidebar and click a document to import and open it. Browsing does not link a document; importing does. Connect Linear first through the [Issues page](/settings/issues#linear).

A linked Page shows its sync status below the editor. You can sync it, open the original or unlink it while keeping the Carbon Page. Linked documents sync in both directions. Page links and attachments stay in Carbon; syncing their Markdown does not upload their files to Linear.

If both sides changed, Carbon preserves both versions and asks which to keep. Linear has no atomic conditional document update, so a remote edit in the brief interval between checking and writing can still race the sync.

## Limits

- **Slides**, **Images** and **Google Drive** in the sidebar are placeholders. They do not create slides or images, or connect to Drive.
- Pages are managed documents, separate from repository Markdown files you open in a session's Docs panel.
- Shortcuts on this page can be changed in Settings → Shortcuts.
