Choose **Design** below **Home** in the left rail, then **New canvas**. Pick an attached project. Carbon saves each canvas under that project’s `canvases/` directory as a `.canvas.json` file.

Open a canvas from the library. Use the toolbar at the bottom to add a frame (**F**), rectangle (**R**) or text (**T**). Choose **Select** (**V**), then click a layer on the canvas or in **Layers** to edit it in the inspector. Edits save automatically.

Open **Theme** to create reusable tokens or import supported token definitions from a project’s `DESIGN.md`. Apply a token in the inspector to keep linked layers in sync when its value changes.

Return to the library to search by name, filter by project, move canvases into folders, or restore a canvas from **Archive**.

## Edit a canvas beside a conversation

When a conversation uses a canvas, its **Design** button appears beside the other session tools. Click it to edit the most recently used canvas while you chat. To open another linked canvas, choose its name under **Design canvases** in the pinned summary. Edits save to the same project file you see in the Design workspace.
